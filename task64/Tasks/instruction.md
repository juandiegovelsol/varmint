# Follow border rendering issue

When you follow someone in a shared session, the editor draws a colored border around the edge of the viewport to show you're following them. Something about it isn't right — the attached screenshot (`follow_indicator_reference.png`, in this task's assets) shows what's wrong.

Fix it so the border renders correctly.

Following someone also has other problems. If the person you're following has a different window shape than yours, you don't end up seeing everything they can currently see, and if they switch to a different page, you don't end up on that page with them. Fix those too.
