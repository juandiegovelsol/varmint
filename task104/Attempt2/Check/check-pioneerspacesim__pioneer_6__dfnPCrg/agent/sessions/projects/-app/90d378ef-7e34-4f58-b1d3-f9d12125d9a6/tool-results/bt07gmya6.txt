# Ship is damaged when performing the action shown in the recording

### What happens
`recording.mp4` shows a ship performing an action at a station. The action does not
go the way it is set up to go, and the ship does not come out of it unharmed.
The collision outlines of the ship and the pad already overlap while the ship sits still, although the video shows it resting clear of the pad. A ship that really lands on a pad must still be caught by it, and the ship's overall shape must stay as it is.

### Expected
Performing the action shown in the recording must not damage the ship at all, at the spot shown in
the video or at any other equivalent spot of the same station. The hull-integrity readout stays at
100% for the whole action.

## Attached visual evidence

- `/app/.harbor_assets/recording.mp4`

You can inspect the video frame by frame with `ffmpeg` (installed in the image), e.g. extracting
still frames at specific timestamps to look closely at the HUD and the ship.

# Behavioral verifier. Resets every path test.patch touches to the immutable harbor_base tag, applies
# the hidden tests, runs ONLY the configured f2p + p2p tests with the repository's own runner into a
# JUnit report, and lets verifier.py turn that report into the reward. Nothing here reads the
# candidate's source to decide anything.
set -uo pipefail

# ---- task-specific values, filled by the task builder ----------------------------------------
# run_tests runs the configured tests with the repository's own runner and writes JUnit XML to
# $JUNIT_OUT. The test ids (f2p + p2p from /tests/config.json) are in $TEST_IDS_FILE, one per line.
# Write plain shell commands here; no quoting of the whole block is needed.
run_tests() {
  # Pioneer collects src/test/*.cpp via a plain file(GLOB) with no CONFIGURE_DEPENDS, so a
  # freshly-applied test.patch adding a new test file is invisible to the build until we
  # reconfigure.
  cmake -S /app -B build

  # Compile just what's needed to run the unit tests (keeps this fast and avoids needing a GL
  # context / display at all -- the collision-mesh test uses Pioneer's own headless dummy renderer).
  cmake --build build --target unittest -- -j2

  # Build a doctest test-case filter "Name One,Name Two,..." from the configured test ids. Test
  # case names may contain spaces, so this must stay a single argv entry (no unquoted expansion)
  # when passed to the binary below.
  FILTER_ARG=""
  while IFS= read -r name; do
    [ -z "$name" ] && continue
    if [ -z "$FILTER_ARG" ]; then FILTER_ARG="$name"; else FILTER_ARG="$FILTER_ARG,$name"; fi
  done < "$TEST_IDS_FILE"

  # doctest's junit reporter; run from the repo root so FileSystem::Init() (PIONEER_LOCAL_DATA_ONLY=1)
  # finds ./data. Don't let a failing test (expected on the base commit) abort this script before
  # the JUnit XML has been written.
  ./build/unittest --reporters=junit "--out=$JUNIT_OUT" "-tc=$FILTER_ARG"
  true
}

"""Turn the JUnit report into the task reward.

The reward is binary: 1.0 only when every configured f2p and p2p test is found exactly once in the
report and passed; otherwise 0.0. f2p_passed / f2p_total and p2p_passed / p2p_total record how close
a run came. A `--rubric fail` verdict zeroes the reward; absent or ungraded never lowers it
(rubric_passed = -1). The verifier reads test outcomes only, never the candidate's source.
"""
import html
import json
import os
import sys
import xml.etree.ElementTree as ET

# Canonical reward writer + --rubric gate. Proven against a real harbor run, and verified
# against all five outcome cases (perfect run, failed rubric, ungraded rubric, partial f2p,
# p2p regression).
#
# verifier.py carries TASK-SPECIFIC logic, so this is a PROPOSAL to merge by hand.
#
# CRITICAL - reward.json MUST be a FLAT map of numbers, and exactly these seven keys:
#     {reward, tests_passed, f2p_passed, f2p_total, p2p_passed, p2p_total, rubric_passed}
# harbor parses it as VerifierResult.rewards: dict[str, float | int] and takes it in
# PREFERENCE to reward.txt. A nested dict, list, string or None raises a pydantic
# ValidationError that aborts the trial BEFORE any reward is recorded - while reward.txt
# still gets written inside the container, so the run looks scored when harbor in fact
# stored nothing.
#   rubric_passed: 1 pass / 0 fail / -1 not graded (no rubric shipped, or judge unavailable).
#
# THE POLICY IS BINARY. tests_passed is 1.0 only when every f2p passes AND every p2p still
# passes; a strict subset of f2p passing is 0.0, NOT 0.5. Partial credit would let a half-fix
# read as "solved" to pass@k, and nothing is lost by collapsing it because the four count keys
# carry the detail. An earlier version of this template documented reward.txt as a float in
# {0.0, 0.5, 1.0} with a failed rubric capping at 0.5; both were wrong.
#
# Registered with atexit so it writes LAST and overrides whatever a pre-existing local reward
# block already wrote - which is what makes this a safe patch onto a task being repaired
# rather than a rewrite of its scoring.

import atexit, json as _cj, os as _co, sys as _cs

_CANON_JSON = "/logs/verifier/reward.json"
_CANON_TXT = "/logs/verifier/reward.txt"
_canon = {}


def canon_reward(f2p_passed, f2p_total, p2p_passed, p2p_total, rubric):
    """THE reward policy for the whole corpus. BINARY -- there is no partial credit.

    tests_passed is 1.0 only when every f2p test passes AND every p2p test still passes. A
    strict subset of f2p passing is not partial progress worth scoring: the task is unsolved,
    so it is 0.0.

    reward is the same value, zeroed when the rubric judge failed a criterion. A "pass" or a
    "not graded" verdict never lowers the score -- the judge must never be able to penalise a
    run it could not grade.
    """
    f, t = int(f2p_passed), int(f2p_total)
    p, q = int(p2p_passed), int(p2p_total)
    solved = bool(t) and f == t and p == q
    tests_passed = 1.0 if solved else 0.0
    _canon.clear()
    _canon.update({
        "reward": 0.0 if rubric == "fail" else tests_passed,
        "tests_passed": tests_passed,
        "f2p_passed": f, "f2p_total": t,
        "p2p_passed": p, "p2p_total": q,
        "rubric_passed": {"pass": 1, "fail": 0}.get(rubric, -1),
    })
    return _canon["reward"]


@atexit.register
def _canon_flush():
    if not _canon:
        return
    try:
        _co.makedirs(_co.path.dirname(_CANON_JSON), exist_ok=True)
        with open(_CANON_JSON, "w") as _h:
            _cj.dump(_canon, _h, indent=2)
        # reward.txt too: harbor prefers reward.json, but the sandbox teardown script and the
        # lighthouse UI read reward.txt. Writing both from one dict means they cannot disagree.
        with open(_CANON_TXT, "w") as _h:
            _h.write(str(_canon["reward"]))
    except Exception as _exc:
        print("WARNING: could not write %s: %s" % (_CANON_JSON, _exc), file=_cs.stderr)


def rubric_verdict(argv):
    """The verdict test.sh hands in as `--rubric pass|fail|""`.

    Anything that is not an explicit pass/fail -- including the empty string test.sh passes
    when judge.py wrote no verdict -- means "not graded", which must never penalise the run.
    """
    if "--rubric" not in argv:
        return None
    i = argv.index("--rubric")
    value = argv[i + 1].strip().lower() if i + 1 < len(argv) else ""
    return value if value in ("pass", "fail") else None

def load_junit(path):
    """Every reported test, keyed by "classname name" and by name; a key seen twice with different
    outcomes counts as failed."""
    results = {}
    if not os.path.exists(path):
        return results
    try:
        root = ET.parse(path).getroot()
    except ET.ParseError:
        return results
    for tc in root.iter("testcase"):
        tags = {c.tag for c in tc}
        outcome = "skip" if "skipped" in tags else ("fail" if tags & {"failure", "error"} else "pass")
        full = f"{tc.get('classname', '')} {tc.get('name', '')}".strip()
        for key in {full, tc.get("name", "")}:
            if key in results and results[key] != outcome:
                results[key] = "fail"
            else:
                results[key] = outcome
    return results


def junit_key(test_id):
    """A pytest node id (tests/test_x.py::TestA::test_b[png]) as the JUnit report names it
    ("tests.test_x.TestA test_b[png]"); other ids unchanged."""
    if "::" not in test_id:
        return test_id
    parts = test_id.split("::")
    mod = parts[0][:-3] if parts[0].endswith(".py") else parts[0]
    return f"{'.'.join([mod.replace('/', '.')] + parts[1:-1])} {parts[-1]}"


def resolve(test_id, results):
    """The outcome of one configured test: an exact key match first (the id as written, or a
    pytest node id in JUnit form), else the single reported test whose key ends with it. Missing
    or ambiguous counts as not passed."""
    keys = [test_id, junit_key(test_id)]
    if " :: " in test_id:  # "file :: describe › test" (playwright list output)
        keys.append(test_id.replace(" :: ", " ", 1))
    if " > " in test_id:  # "describe > test": jest-junit joins with a space, playwright with " › "
        head, rest = test_id.split(" > ", 1)
        keys += [test_id.replace(" > ", " "), test_id.replace(" > ", " › "), head + " " + rest.replace(" > ", " › ")]
    keys += [k.replace('"', "") for k in keys]  # jest-junit drops quotation marks from names
    keys += [html.unescape(k) for k in keys]  # an id copied from a JUnit file may keep &apos; &quot;
    keys = list(dict.fromkeys(keys))
    for key in keys:
        if key in results:
            return results[key]
    for key in keys:
        hits = {k: v for k, v in results.items() if k.endswith(key)}
        if hits and len(set(hits.values())) == 1:
            return next(iter(hits.values()))
        if hits:
            return "ambiguous"
    # "file > test" with a describe level left out: a test in that file whose name ends the same
    parts = test_id.split(" > ")
    if len(parts) >= 2 and ("." in parts[0] or "/" in parts[0]):
        hits = {k: v for k, v in results.items() if k.startswith(parts[0] + " ") and k.endswith(parts[-1])}
        if hits and len(set(hits.values())) == 1:
            return next(iter(hits.values()))
        if hits:
            return "ambiguous"
    return "missing"
