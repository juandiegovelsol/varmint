=== instruction.md
# Focus ends up in the wrong place

Two scenarios, A and B, are captured frame by frame in the attached images. Each caption states the action performed, and the ring marks where keyboard focus is afterwards.

In each scenario the last frame (A4 and B3) shows a wrong result. The matching "Expected" image shows where focus should go instead.

![A1](/app/.harbor_assets/focus_trace_1.png)

![A3](/app/.harbor_assets/focus_trace_3.png)
![A4](/app/.harbor_assets/focus_trace_4.png)
![A expected](/app/.harbor_assets/expected_A.png)
![B1](/app/.harbor_assets/disabled_trace_1.png)
![B2](/app/.harbor_assets/disabled_trace_2.png)
![B3](/app/.harbor_assets/disabled_trace_3.png)
![B expected](/app/.harbor_assets/expected_B.png)

## Expected

Make both scenarios behave as in the Expected images. Each Expected image shows one acceptable outcome; what matters is where focus goes relative to the buttons on the page.

Keep all other behavior unchanged, including the earlier frames and whatever the same keys do afterwards.

## Attached visual evidence

- `/app/.harbor_assets/screen.png`
- `/app/.harbor_assets/focus_trace_1.png` … `focus_trace_4.png`
- `/app/.harbor_assets/expected_A.png`
- `/app/.harbor_assets/disabled_trace_1.png` … `disabled_trace_3.png`
- `/app/.harbor_assets/expected_B.png`

Inspect every attached file before making changes. The images describe observable behavior; they do not prescribe source files, internal names, or an implementation strategy.

#!/usr/bin/env bash
# Behavioral verifier. Resets every path test.patch touches to the immutable harbor_base tag, applies
# the hidden tests, runs ONLY the configured f2p + p2p tests with the repository's own runner into a
# JUnit report, and lets verifier.py turn that report into the reward. Nothing here reads the
# candidate's source to decide anything.
set -uo pipefail

# ---- task-specific values, filled by the task builder ----------------------------------------
# run_tests runs the configured tests with the repository's own runner and writes JUnit XML to
# $JUNIT_OUT. The test ids (f2p + p2p from /tests/config.json) are in $TEST_IDS_FILE, one per line.
# Write plain shell commands here; no quoting of the whole block is needed.
run_tests() {
  npx vitest run \
    examples/toolbar-active-id-disabled/test.ts \
    examples/toolbar-active-id-stale/test.ts \
    examples/composite/test.ts \
    examples/toolbar/test.ts \
    examples/tab/test.ts \
    examples/radio/test.ts \
    --reporter=junit --outputFile="$JUNIT_OUT"
}
# Directories holding the repo's test plumbing (configs, helpers) that must also be restored so a
# candidate cannot replace the harness. Space-separated, relative to /app; '' if none.
PROTECTED_DIRS='examples/composite/test.ts examples/toolbar/test.ts examples/tab/test.ts examples/radio/test.ts vitest.config.ts vitest.setup.ts package.json'
# -----------------------------------------------------------------------------------------------

mkdir -p /logs/verifier
STDOUT_LOG=/logs/verifier/test-stdout.txt
STDERR_LOG=/logs/verifier/test-stderr.txt
export JUNIT_OUT=/logs/verifier/junit.xml
export TEST_IDS_FILE=/logs/verifier/test_ids.txt
: > "$STDOUT_LOG"; : > "$STDERR_LOG"
rm -f "$JUNIT_OUT" /logs/verifier/reward.txt /logs/verifier/reward.json

ensure_reward() { [ -f /logs/verifier/reward.txt ] || echo 0 > /logs/verifier/reward.txt; }
trap ensure_reward EXIT

cd /app || { echo "no /app" | tee -a "$STDERR_LOG"; exit 1; }

# Capture the agent's submission BEFORE anything below mutates /app -- this is the last
# moment the tree is base + agent work; the restore loop and test.patch come next.
#
# A THROWAWAY INDEX, never /app/.git/index: `git add` against the real one would leave paths
# staged and change how the `git checkout harbor_base --` and `git clean` below behave.
#
# TRACKED EDITS + A SOURCE WHITELIST, not `add -A` with a blacklist. This image builds wx
# in-tree AFTER the harbor_base commit (environment/Dockerfile), so everything the build
# emits is untracked and NOT in wx's .gitignore. A bare `add -A` captured 380MB of .o/.d/.so;
# excluding those by extension still left ~120 configure-generated files (samples/*/Makefile,
# bk-deps, version-script, lib/wx/config/*, the utils/wxrc/wxrc binary) because most have no
# extension to blacklist. Inverting it -- stage tracked modifications, then add only untracked
# files that LOOK like source -- keeps the agent's work and drops generated output by default.
_SUB=/logs/verifier/submission.patch
_SUBIDX=/tmp/.submission_index
_SUBSRC=('*.c' '*.cc' '*.cpp' '*.cxx' '*.h' '*.hh' '*.hpp' '*.hxx' '*.inl' '*.m' '*.mm'
         '*.py' '*.rb' '*.go' '*.rs' '*.java' '*.js' '*.ts' '*.tsx' '*.cs' '*.kt' '*.swift')
rm -f "$_SUBIDX"
GIT_INDEX_FILE="$_SUBIDX" git -C /app read-tree harbor_base 2>>"$STDERR_LOG" || true
GIT_INDEX_FILE="$_SUBIDX" git -C /app add -u 2>>"$STDERR_LOG" || true
# Enumerate before adding: `git add` aborts and stages NOTHING if any one pathspec matches
# no file, which silently drops the agent's new files on most tasks.
# Generated-output dirs are dropped from the UNTRACKED scan only. A project that keeps real
# source under lib/ is unaffected: those files are tracked at harbor_base, so `add -u` above
# already has them. This drops only files CREATED under a build dir during the run -- which,
# left in, break replay: they are recorded as new-file hunks and a fresh container from the
# same image already has them, so `git apply` fails with "already exists in working directory".
mapfile -t _SUBNEW < <(git -C /app ls-files --others --exclude-standard \
  -- "${_SUBSRC[@]}" ':(exclude)lib/' ':(exclude)build/' ':(exclude).deps/' 2>/dev/null)
if [ "${#_SUBNEW[@]}" -gt 0 ]; then
  GIT_INDEX_FILE="$_SUBIDX" git -C /app add -- "${_SUBNEW[@]}" 2>>"$STDERR_LOG" || true
fi
GIT_INDEX_FILE="$_SUBIDX" git -C /app diff --binary --cached harbor_base \
  > "$_SUB" 2>>"$STDERR_LOG" || true
rm -f "$_SUBIDX"

# WHAT THE WHITELIST DROPPED, listed rather than silently discarded. The split above captures
# every change to a TRACKED file (any extension, deletions included) but only NEW files that
# look like source -- so an agent adding config.yml, a .cmake module or an extensionless script
# loses it, and the patch still looks clean. That is the failure this manifest exists to expose.
#
# NEWEST FIRST, which is the useful ordering and not a cosmetic one: build output and image
# assets are created before the agent phase starts, so anything the agent made sorts to the top.
# Build artifacts are excluded by the same rules as the capture, to keep the list readable.
#
# If something here belongs in the submission, widen _SUBSRC. Do not reach for `add -A`.
_SUBSKIP=/logs/verifier/submission-skipped.txt
_SUBCAP=/tmp/.submission_captured
if [ "${#_SUBNEW[@]}" -gt 0 ]; then printf '%s\n' "${_SUBNEW[@]}" > "$_SUBCAP"; else : > "$_SUBCAP"; fi
_SUBSKIPN=$(git -C /app ls-files --others --exclude-standard -- . \
    ':(exclude)lib/' ':(exclude)build/' ':(exclude).deps/' \
    ':(exclude)*.o' ':(exclude)*.d' ':(exclude)*.a' ':(exclude)*.lo' ':(exclude)*.la' \
    ':(exclude)*.so' ':(exclude)*.so.*' ':(exclude)*.gch' ':(exclude)*.pyc' 2>/dev/null \
  | grep -vxF -f "$_SUBCAP" 2>/dev/null | wc -l)
{ echo "# Untracked files NOT captured into submission.patch, newest first."
  echo "# Anything the agent created sorts above build output, which predates the agent phase."
  echo "# total: ${_SUBSKIPN}  (showing at most 40)"
  git -C /app ls-files --others --exclude-standard -- . \
      ':(exclude)lib/' ':(exclude)build/' ':(exclude).deps/' \
      ':(exclude)*.o' ':(exclude)*.d' ':(exclude)*.a' ':(exclude)*.lo' ':(exclude)*.la' \
      ':(exclude)*.so' ':(exclude)*.so.*' ':(exclude)*.gch' ':(exclude)*.pyc' 2>/dev/null \
    | grep -vxF -f "$_SUBCAP" 2>/dev/null | head -200 \
    | while IFS= read -r _f; do
        printf '%s\t%s\t%s\n' "$(stat -c %Y "/app/$_f" 2>/dev/null || echo 0)" \
                              "$(stat -c %s "/app/$_f" 2>/dev/null || echo 0)" "$_f"
      done \
    | sort -rn | head -40 | awk -F'\t' '{printf "%s\t%s\t%s\n",$1,$2,$3}'
} > "$_SUBSKIP" 2>/dev/null || true
rm -f "$_SUBCAP"

# Size guard. The whitelist is a heuristic, so a task laying out source unusually could still
# produce something enormous. Cap it and leave a diagnosable stub: a truncated capture is
# recoverable, a full disk is not.
_SUBSZ=$(wc -c < "$_SUB" 2>/dev/null || echo 0)
if [ "$_SUBSZ" -gt 5242880 ]; then
  { echo "SUBMISSION CAPTURE SUPPRESSED: ${_SUBSZ} bytes exceeds the 5MB cap."
    echo "Directories contributing to the discarded patch:"
    grep -a "^diff --git" "$_SUB" | sed 's#^diff --git a/##; s# b/.*##; s#/[^/]*$##' \
      | sort | uniq -c | sort -rn | head -20
  } > "$_SUB.suppressed" 2>/dev/null
  : > "$_SUB"
  echo "== submission.patch SUPPRESSED (${_SUBSZ} bytes > 5MB cap) ==" | tee -a "$STDOUT_LOG"
else
  echo "== captured submission.patch (${_SUBSZ} bytes, $(grep -ac '^diff --git' "$_SUB" 2>/dev/null || echo 0) files) ==" \
    | tee -a "$STDOUT_LOG"

=== tests/verifier.py
#!/usr/bin/env python3
"""Turn the JUnit report into the task reward.

The reward is binary: 1.0 only when every configured f2p and p2p test is found exactly once in the
report and passed; otherwise 0.0. f2p_passed / f2p_total and p2p_passed / p2p_total record how close
a run came. The verifier reads test outcomes only, never the candidate's source.
"""
import atexit
import json
import os
import sys
import xml.etree.ElementTree as ET

import json as _cj, os as _co, sys as _cs

_CANON_JSON = "/logs/verifier/reward.json"
_CANON_TXT = "/logs/verifier/reward.txt"
_canon = {}


def canon_reward(f2p_passed, f2p_total, p2p_passed, p2p_total, rubric):
    """THE reward policy for the whole corpus. BINARY -- there is no partial credit.

    tests_passed is 1.0 only when every f2p test passes AND every p2p test still passes. A
    strict subset of f2p passing is not partial progress worth scoring: the task is unsolved,
    so it is 0.0.

    reward is the same value, zeroed when the rubric judge failed a criterion. A "pass" or a
    "not graded" verdict never lowers the score -- the judge must never be able to penalise a
    run it could not grade.
    """
    f, t = int(f2p_passed), int(f2p_total)
    p, q = int(p2p_passed), int(p2p_total)
    solved = bool(t) and f == t and p == q
    tests_passed = 1.0 if solved else 0.0
    _canon.clear()
    _canon.update({
        "reward": 0.0 if rubric == "fail" else tests_passed,
        "tests_passed": tests_passed,
        "f2p_passed": f, "f2p_total": t,
        "p2p_passed": p, "p2p_total": q,
        "rubric_passed": {"pass": 1, "fail": 0}.get(rubric, -1),
    })
    return _canon["reward"]


@atexit.register
def _canon_flush():
    if not _canon:
        return
    try:
        _co.makedirs(_co.path.dirname(_CANON_JSON), exist_ok=True)
        with open(_CANON_JSON, "w") as _h:
            _cj.dump(_canon, _h, indent=2)
        # reward.txt too: harbor prefers reward.json, but the sandbox teardown script and the
        # lighthouse UI read reward.txt. Writing both from one dict means they cannot disagree.
        with open(_CANON_TXT, "w") as _h:
            _h.write(str(_canon["reward"]))
    except Exception as _exc:
        print("WARNING: could not write %s: %s" % (_CANON_JSON, _exc), file=_cs.stderr)


def rubric_verdict(argv):
    """The verdict test.sh hands in as `--rubric pass|fail|""`.

    Anything that is not an explicit pass/fail -- including the empty string test.sh passes
    when judge.py wrote no verdict -- means "not graded", which must never penalise the run.
    """
    if "--rubric" not in argv:
        return None
    i = argv.index("--rubric")
    value = argv[i + 1].strip().lower() if i + 1 < len(argv) else ""
    return value if value in ("pass", "fail") else None


CONF = json.load(open("/tests/config.json"))
F2P, P2P = CONF["f2p"], CONF["p2p"]
REPORT = os.environ.get("JUNIT_OUT", "/logs/verifier/junit.xml")
OUT_DIR = "/logs/verifier"


def load_junit(path):
    """Every reported test, keyed by "classname name" and by name; a key seen twice with different
    outcomes counts as failed."""
    results = {}
    if not os.path.exists(path):
        return results
    try:
        root = ET.parse(path).getroot()
    except ET.ParseError:
        return results
    for tc in root.iter("testcase"):
        tags = {c.tag for c in tc}
        outcome = "skip" if "skipped" in tags else ("fail" if tags & {"failure", "error"} else "pass")
        full = f"{tc.get('classname', '')} {tc.get('name', '')}".strip()
        for key in {full, tc.get("name", "")}:
            if key in results and results[key] != outcome:
                results[key] = "fail"
            else:
                results[key] = outcome
    return results


def junit_key(test_id):
    """A pytest node id (tests/test_x.py::TestA::test_b[png]) as the JUnit report names it
    ("tests.test_x.TestA test_b[png]"); other ids unchanged."""
    if "::" not in test_id:
        return test_id
    parts = test_id.split("::")
    mod = parts[0][:-3] if parts[0].endswith(".py") else parts[0]
    return f"{'.'.join([mod.replace('/', '.')] + parts[1:-1])} {parts[-1]}"


def resolve(test_id, results):
    """The outcome of one configured test: an exact key match first (the id as written, or a
    pytest node id in JUnit form), else the single reported test whose key ends with it. Missing
    or ambiguous counts as not passed."""
    keys = [test_id, junit_key(test_id)]
    if " > " in test_id:  # "describe > test": jest-junit joins with a space, playwright with " › "
        head, rest = test_id.split(" > ", 1)
        keys += [test_id.replace(" > ", " "), test_id.replace(" > ", " › "), head + " " + rest.replace(" > ", " › ")]
    keys += [k.replace('"', "") for k in keys]  # jest-junit drops quotation marks from names
    keys = list(dict.fromkeys(keys))
    for key in keys:
        if key in results:
            return results[key]
    for key in keys:
        hits = {k: v for k, v in results.items() if k.endswith(key)}
        if hits and len(set(hits.values())) == 1:
            return next(iter(hits.values()))
        if hits:
            return "ambiguous"
    # "file > test" with a describe level left out: a test in that file whose name ends the same
    parts = test_id.split(" > ")
    if len(parts) >= 2 and ("." in parts[0] or "/" in parts[0]):
        hits = {k: v for k, v in results.items() if k.startswith(parts[0] + " ") and k.endswith(parts[-1])}
        if hits and len(set(hits.values())) == 1:
            return next(iter(hits.values()))
        if hits:
            return "ambiguous"
    return "missing"


def main():
    results = load_junit(REPORT)
    detail = {}
    f2p_ok = 0
    for t in F2P:
        r = resolve(t, results)
        detail[f"f2p::{t}"] = r
        f2p_ok += r == "pass"
    p2p_ok = 0
    for t in P2P:
        r = resolve(t, results)
        detail[f"p2p::{t}"] = r
        p2p_ok += r == "pass"
    canon_reward(f2p_ok, len(F2P), p2p_ok, len(P2P), rubric_verdict(sys.argv[1:]))
    reward = dict(_canon)
    os.makedirs(OUT_DIR, exist_ok=True)
    json.dump(detail, open(f"{OUT_DIR}/reward_detail.json", "w"), indent=2)
    print(json.dumps(reward))


if __name__ == "__main__":
    main()
