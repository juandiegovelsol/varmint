# Some objects misbehave in the forest

### What happens
`recording.mp4` is an uncut clip in a forest level. Several things that happen with the objects Tux grabs in the video are not how those objects work in this game. For example, while Tux carries one, it is on the wrong side of him. The other problems are in how one is let go, how it falls, where it comes to rest, how it and the other things in the level affect each other, and what happens when Tux meets one that is lying on the ground.

### Expected
These objects should behave like they normally do in this game, in every situation the clip shows. The game treats everything by the same rules, so the other problems show up in the recording as things that don't match the same kind of thing elsewhere in the same clip, or that look out of place in this level. Fix every problem involving these objects that you can see in the recording.
