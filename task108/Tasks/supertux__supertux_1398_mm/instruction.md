# Some objects misbehave in the forest

### What happens
`recording.mp4` is an uncut clip in a forest level. Several things that happen with the objects Tux grabs in the video are not how those objects work in this game.

### Expected
The objects that are grabbed in the video should behave like they normally do in this game. Tux should carry them in front of him and throw them the way he is walking. When one falls, it should drop past coins as if they weren't there, knock out any enemy it lands on, and stay on top of the ground once it lands. Once it is lying there, Tux should be able to stand on it and should not be able to walk through it. Fix every problem with these objects that you can see in the recording.
