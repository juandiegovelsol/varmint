# Part of a selection is left unformatted

Selecting an inline chip together with the ordinary text right next to it and applying the action
visible in the image doesn't format both parts the same way — one part changes and the other
doesn't, from that single action. Selecting plain text on its own and applying the same action to
it works as expected, so the chip's presence is what causes the split. See the attached screenshots
for exactly which part changes and which stays put.
